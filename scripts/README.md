# 脚本工具与核心引擎 (scripts) 说明文档

## 📌 目录定位
- **路径**：`scripts/`
- **主要作用**：用于存放与管理股票分析、实时行情抓取、技术指标计算、量化评分、持仓监控、矢量图表生成及终端 CLI 核心引擎。

---

## 📋 文件收纳与命名规范
1. **文件分类**：仅存放可执行 Python 脚本与 Shell 运维脚本；
2. **命名格式**：Python 脚本统一使用 `stock_*.py` 或 `dsh_*.py`，Shell 脚本统一使用 `*.sh`；
3. **关联文档**：所有对外命令行工具必须在 `README.md` 中提供用法示例。

---

## 🛠️ 维护与更新原则
- 脚本必须基于 Python 3 标准库，具备零外部依赖、高鲁棒性与异常降级能力；
- 遵循写后读回与 100% 自动化测试覆盖。
