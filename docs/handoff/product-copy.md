## 三、短文案（80~120 字，仓库/产品简介位）

> **DSH股票**是一个运行在本机的 A 股量化分析工作台。它覆盖沪深京全量标的（实测 4601 只），提供多维条件选股、实时行情、缠论六类买卖点自动标记、技术指标与 100 分制多空评分、持仓风险体检与止盈止损预警。数据全部来自公开真实来源，缺失即如实提示未获取；零第三方依赖，Web 与命令行双入口，打开即用。

## 四、标准介绍（250~350 字）

> **DSH股票**把 A 股研究中最常用的几件事收进了同一个本地应用：**选股、看图、判点、体检、预警**。
>
> 打开网页，你面对的是 9 个工作区：全市场股票列表（流动性、市值、PE、行业、ST、换手率等多维筛选）、仪表盘、宏观环境、股东研究、指数行情、数据中心（抓取审计与新鲜度）、缠论雷达、策略选股、持仓体检。点开任意一只个股，默认就是「分时图 + 日线图」左右并排，日线/周线/季线、5 分 K 线各颗粒度都自动标注缠论的买 1/2/3 与卖 1/2/3 —— 每处标记都写明级别与判定依据，识别不到就如实显示 0。
>
> 底层是一条**只认真实数据**的链路：行情、股东、公告、分红、大宗交易全部取自公开来源并留下可追溯缓存；成交额缺失时用「均价 × 成交量」兜底并在图上明确标注「含估算」；来源没披露时直接写「未获取」，绝不补 0、绝不模拟。整个系统零第三方依赖，装好 Python 就能跑，数据留在自己机器上。

## 五、长文案（600~800 字，用于完整产品介绍 / 项目主页）

> ### 你的电脑上，可以有这样一个 A 股工作台
>
> 大多数行情软件的问题是：你要的功能分散在五六个页面，指标口径不透明，数据从哪来、新不新鲜全靠猜。**DSH股票** 换了一个思路 —— 把「真实」和「一体」放在最前面。
>
> **一、全市场，多维筛。** 沪深京 4601 只标的收在一张表里，流动性（日交易额/日均交易额）、市值、PE、行业、板块、ST 风险、换手率等维度组合筛选，服务端实时计算，结果只按真实量比排序。
>
> **二、看图，一次看全。** 个股详情默认「当日分时 + 日线图」双图并排，周线、季线、5 分 K 线随时切换；成交额、成交量、换手率三档副图（含总和、平均、地量、天量、中位数四维分布）；缩放只改"画面里显示多少根 K 线"，下限 30 根、上限该颗粒度全部历史。绘图区还带 1~4 根多阶筹码峰自动画线，重心压力位一眼可见。
>
> **三、判点，讲依据。** 缠论是最容易被"玄学化"的部分，这里选择把它讲清楚：买 1/2/3 与卖 1/2/3 六类买卖点在日线、周线、季线、当日分时、5 分 K 线上**默认全部自动标记**，每个标记都标注所属级别（日线级别 / 周线级别 / 季线级别 / 分时级别 / 5 分级别）与判定依据（例如"第一类买点之后的第一次回调收于某价"）。算法严格按缠论定义实现，只有一套，不落库、不另起第二套；识别不到就是 0，不补造。
>
> **四、体检，管风险。** 填入真实持仓后，系统给出持仓盈亏、静态与动态止盈止损规则（跌破 MA20、缠论卖点、移动回撤）与风险提示。**注意：底册为空时它一律拒绝输出结论** —— 宁可说"未配置"，也不给你一个假的 0 元。
>
> **五、不编数据。** 这是全工程最硬的一条规矩：数据只从公开来源取，成交额缺失走「均价 × 成交量」兜底并在图上标注「含估算：均价 × 成交量」；来源未披露就显示「未获取」。历史上的无来源缓存被隔离，不参与任何计算。
>
> **v5.5.0 更新：** 新增 `db-archive` 数据库归档体检命令；前端完成模块化拆分第一步（纯函数外置）；发版不再需要重启服务端。
>
> **技术底色：** Python 标准库零依赖，SQLite 本地落库，纯手写 SVG 矢量图表，Web 与 16 个命令行子命令共用同一套引擎；266 项 Python 单测 + 7 套前端静态回归 + 5 套真机浏览器回归（headless Chrome 打真实页面）验收全部留痕。
>
> 它不替你做决定，它只是把决定需要的东西，一次性、真实地摆在你面前。

## 七、版本文案（最新 v5.4.0 · R09 / v5.3.0 · R08，对用户说的人话）

> **本次更新（v5.4.0）**
>
> 1. **行情日期精确到分**：顶栏日期不再是「2026年9月23日」，而是来源真实快照时间「2026年9月24日 13:18」。时间取自行情来源自身的时间戳（可核对原始值），**只给到日就只显示日，拿不到就显示"未获取"** —— 不会拿电脑本地时间或数据库批次日期冒充行情时间。
> 2. **副图文字不再叠在一起**：个股日K（成交额 / 成交量 / 换手率）、当日分时、大盘指数的副图，标题与「总和 / 平均 / 地量 / 天量 / 中位数」现在按各自真实宽度依次排开，标题再长也不会压到数字上；空间不够时自动换行，绝不叠画、绝不丢项。
> 3. **顺手修掉三个"看着有数、其实不对"的地方**：副图「总和」此前因为一个字段名写错而永远显示 `--`，现在正常出数并在含估算时标明「（含估算）」；指数副图此前用「指数点数 × 成交量」估算成交额，出现了 `3,943,379.8亿` 这种明显错误的数字，现在改为**只采信来源披露值**，未披露就如实写「不可得」，刻度也显示「不可得」；辅助线交易面积在整段数据都不可得时，不再显示 `0.00亿`（那是"面积为 0"的意思），改为「未交汇」。
>
> 本批同样为**零数据库写入改动**，不动你的历史数据。

> **上一版更新（v5.3.0）**
>
> 1. **缠论买卖点全图自动标记**：买 1/2/3、卖 1/2/3 六类现在在日线、周线、季线、当日分时、5 分 K 线上**默认全部打开，打开就标，不用点任何按钮**。每个标记都写明级别（日线级别 / 周线级别 / 季线级别 / 分时级别 / 5 分级别）和判定依据；识别不到就如实显示 0，数据没拿到就不画。
> 2. **周线、季线成交额改为逐日相加**：与日线副图完全同一口径，并在图上标注「含估算 N 根日线」；覆盖不完整时标注缺失根数，**绝不用 0 充当成交额**。
> 3. **分时维度精简**：移除「1 分 K 线」入口，只保留「当日分时 / 5 分 K 线」（后端能力保留）。
> 4. **详情页默认双图**：进入个股即「分时图 + 日线图」左右并排，无需再点「调出」。
>
> 本批为**零数据库写入改动**，不改动你的历史数据。
