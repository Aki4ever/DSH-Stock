## 本轮验证发现并修复的真实缺陷

1. **筛选请求竞态**：快速连续切换类型芯片时，先发的请求后返回并覆盖新筛选结果（S1 筛选仍显示 153 行）。已加入请求序号守卫，过期响应直接丢弃。
2. **可执行性缺失导致误导**：早期版本对结构止损高于现价的买点仍给出「建议股数」，并显示负的风险百分比。已改为结构破坏判定 + 显式拒止。
3. **区间套引用字段缺失时抛 KeyError**：`compute_resonance` 直接下标取 `signal_name`，字段缺失即崩溃。已改为安全取值并给出类型标签回退。
4. **雷达扫描状态条样式失效**：页面使用了未定义的类名，状态条完全失去卡片外观。已改为复用既有 `crawler-monitor-card` 视觉语言。
