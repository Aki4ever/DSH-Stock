## 本轮验证发现并修复的真实缺陷

1. **分时缠论笔一根都画不出来（最严重）**：后端按 `analyze_bars` 的要求用「交易日 + 分钟」生成唯一递增日期（`2026-09-18 09:31`），而分时 K 线的键是 `HH:MM`。`generateChanlunOverlaySVG` 里 x 坐标映射 `globalIdx.get(t)` 拿不到值得到 `undefined`，同时窗口判定 `r.end_time >= first` 也在日期串与分钟串之间做字符串比较而恒为假 —— 结果是「接口状态 available、笔有 21 条，图上却 0 条」。已改为按分钟刻归一化取键（`sameKey` / `idxOf` / `cmpKey`），并对均线缠绕的 `analysis.ma` 字典同步做双键回退。若只看接口返回而不看 DOM，这个缺陷会完全漏过。
2. **分析结果键前缀被误当作「另一套日期」**：上一条的另一面。修复时曾试图让后端只输出 `HH:MM`，但 `analyze_bars` 内部（`build_pens`）按 `time_str` 索引且要求日期唯一递增，压缩键会破坏算法自身不变量。最终选择**保算法不变量、在前端做键归一化**，这也是「复用同一套算法」这一需求的正确落点。
3. **副图切为成交量时，成交额兜底口径的标注会消失**：`summaryBadgesSvg` 的估算标注原先只在「副图＝成交额」时输出，而个股副图默认是成交量，于是「全部成交额都是估算值」这一关键事实在默认视图下不可见。已补成交量视图下的等价标注（含估算根数），并由浏览器断言把关。

## 已知边界与如实记录

- **交易面积不随「来源可得性」补齐**：交易面积按「首个交汇日 → 今天」累计，若区间内某交易日成交额与成交量**同时**缺失，该日无法计入且标签会追加「覆盖不完整」。这是需求明令的「不得以 0 补齐、不得静默出数」，不是缺陷。
- **分时级别的线不可与日线混读**：分时缠论笔＝分钟级笔，图内已标注「缠论（分时级别…）」，端点另带 `level_note`。同一条价格线在日线与分时下价格相同但结构含义不同，**不可互相印证**。
- **分时自动线仍受当日分时范围限制**：交汇与交易面积均只在当日分时点内求解，不引入历史日 K 混合统计（REQ-024 明文约束）。因此分时线上的「未交汇: 0 天」表示锚点在当日最后一根分时点，而非数据缺失。
- **分时缠论的笔中枢可能高度塌陷**：分时点按 `open = close = high = low` 处理，笔中枢的 `high/low` 由笔端点推导，因此中枢矩形在价格轴上很扁（截图中表现为细横带）。这是「分钟点＝1 根 K 线」这一已确认口径的直接推论，不另设分时专用形态学参数。
- **`data/stock_database.db` 随验证更新**：真实行情缓存与审计流水写入产品库，属本项目既有行为；本轮未新增任何合成数据。
