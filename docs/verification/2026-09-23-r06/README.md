## 数据安全声明

本轮**未对 `data/stock_database.db` 执行任何写入、迁移或重建**；周线/季线聚合全部在浏览器内存中以真实日K现场计算（`aggregateBarsForGroup`），不落库、不缓存到磁盘。

## 本轮修复的隐藏缺陷

窗口渲染与异步数据加载之间存在**自触发微任务死循环**：`renderChartPanel` 无条件调用 `loadMinuteKlines`，而 `loadMinuteKlines` 完成后又回调 `renderChartPanel`；当分钟K线已进入缓存后，`await` 立即 resolve，于是「渲染 → 请求 → 渲染」在微任务队列中无限自转，页面主线程被彻底占死（实测切到 5分K线后，浏览器内任何脚本求值均 45 秒超时）。现加两道幂等闸门：① 仅在该颗粒度尚无数据时才发起请求；② 仅当本次确实取回新数据（引用发生变化）时才重绘。分时缠论失败路径同样补上「已尝试」标记，避免失败重试循环。

## R09 后的探针修订（2026-09-24，v5.4.0）

本脚本此前有 10 项因 WIP 把 K 线画布由 860 改为 920、并把「滚轮缩放」按产品需求移除而失效。本批按**「把探针从硬编码改成实测、把交互换成真实入口」**的原则修订（断言意图不变，未删除任何断言）：

| 原断言/探针（R06 交付时） | 修订后 | 依据 |
| :--- | :--- | :--- |
| 绘图区靠 `width === '730'` 找网格矩形（新画布下取不到 → `绘图区 nullpx (x=null)`） | 由 SVG `viewBox` 实测画布宽 + 取最宽背景矩形实测 `x/width`（现测 65~855，宽 790） | 几何必须实测，历史字面量会随画布调整再次失效 |
| 蜡烛计数 `width !== '730'` 过滤 → 把一块无 `fill/stroke` 的背景矩形算成蜡烛（**实绘 31 根**） | 排除所有「与绘图区同宽」的背景矩形（现测 30 根） | 同上（该背景矩形正是漏网的那一块） |
| 「缩放只改根数：绘图区 …恒定」硬比对 `65 / 730` | 与**首个状态的实测几何**比对（`geo0`），并断言几何非空 | 断言意图是「不变」，不是「等于某个历史数字」 |
| 用 `WheelEvent` 驱动缩放（滚轮缩放已按产品需求移除 → 实测 30 根不变，断言恒真或恒假） | 点击**真实浮动 ➕/➖ 按钮**（`zoomKlineChart`）；并**新增**一项断言：滚轮事件不再改变视窗根数 | 探针必须走产品当前的唯一真实入口（`web/app.js`「需求1: 移除K线图手势缩放…只支持点击浮动的 +- 按钮」） |
