## 本轮验证发现并修复的真实缺陷

1. **stale 数据被当成失败而整体放弃**：`fetch_daily_bars` 原先只接受 `available`/`partial`，把来源故障时**真实且已核验**的完整历史缓存也一并丢弃，导致结构分析无谓熄火；同时也没有把「数据非最新」这一关键事实传给下游。已改为四态新鲜度口径并向下游传播，雷达与选股按各自性质分别处置。
2. **未获取被说成无命中**：全部标的都未获取、没有任何一只完成判定时，选股页空态却写「本轮无命中」。已改为明确区分「无结论」与「无命中」，并给出可操作的重试指引。
3. **选股结果按不存在的 score 字段排序**：命中载荷从未写入 `score`，而列表按 `score DESC` 排序，导致排序退化为「全部 NULL 的无意义顺序」。已改为**只按真实存在的判据数值排序**（当日量比降序、代码升序），并刻意**不引入任何「综合评分」**——本项目不承诺收益，用人造分数排序会把筛选结果伪装成预测结论。新增测试断言排序结果等于真实量比的降序排列。
4. **告警失败会占用冷却窗口**：早期实现无论成败都写冷却，一次网络抖动会让同一结构在冷却期内被静默吞掉。已改为**只有成功下发才占用冷却**，失败落库留痕可重试，并由测试正反两向断言。

## 已知边界（如实记录）

- 选股池为 30 只（宽基 ETF + 权重与成长标的），**不覆盖全市场**；未纳入的证券不代表无信号或无风险。
- 策略只实现了「底背驰 + 放量突破中枢」一条，参数（均量窗口 N / 放量倍数 K / 最小突破幅度）可在页面与 CLI 调整，但不同参数下的表现差异未做任何回测或统计评估——本项目**不做收益承诺，也不声称策略有效性**。
- 飞书/钉钉通道因用户尚未提供 Webhook，**未做过真实下发联调**；已通过签名对照（独立 HMAC 计算）、脱敏、未配置不请求、dry-run 零网络、非 https 拒绝、流水不含密钥等 14 项测试把关，但真实网络下发仍需用户在配置后确认。
- 来源 `web.ifzq.gtimg.cn` 的 HTTP 501 为外部临时状况，恢复后选股与雷达的真实命中会自然恢复，无需改代码。
