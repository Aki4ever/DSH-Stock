## 三、本轮顺带修复的真实缺陷（如实登记）
1. **分钟K线缠论标记整体错位**：`generateChanlunOverlaySVG` 的键函数只取 `date` 字段，而分钟K线的键是 `date`＋`time` 两个字段 —— 同一天的全部分钟K线折叠成同一个键，导致缠论端点与买卖点无法定位（`offset` 退化为 0）。已改为「日期＋时间」合成键，并新增「视窗末尾对齐」的 `offset` 兜底；修复后 5分K线的 7 个买卖点与后端逐类一致（修复前实测无法与后端对齐）。
2. **图上两段成交额文字重叠**：「其中 N 根成交额为估算」与「总成交额」原本画在同一坐标 (m.left+8, subTopY+sh+11)。已把估算警示改为右对齐，两段文字分列左右。
