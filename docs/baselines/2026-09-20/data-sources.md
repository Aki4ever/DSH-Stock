# v4.5.0 数据来源与缺失口径

| 数据 | 实际来源/代码 | 覆盖与限制 |
|---|---|---|
| 行情 | HTTPS 腾讯证券 qt.gtimg.cn；verified_quotes.py | 本次4601个已收录标的；显示实际报价时间，缓存过期标注；不等于市场所有证券 |
| 日线 | 腾讯 ifzq，market_history/history_service | 不复权，逐页回溯；各证券独立缓存；成交额/换手率缺失不估算 |
| 分时 | 腾讯 minute/query，real_chart_engine | 09:30–11:30、13:00–15:00实际返回点；记录来源日期，累计量额按差值转换；失败不可用 |
| 股东姓名 | 东方财富Choice RPT_DMSK_HOLDERS | 本次1870页；按姓名去重，保存历次采集；未来披露/报告记录排除，不代表全部账户 |
| 增减持 | 东方财富Choice，shareholder_actions | 近90/365日公告窗，实际变动数量和已结束记录；部分失败显式partial |
| 财务 | 东方财富Choice利润表/资产负债表/现金流表 | 最近5个年报/季度；累计流量季度差分；缺科目null |
| 公司资料 | 东方财富CompanySurveyAjax | 来源返回的法人、地址、行业、注册资本；缺字段未获取 |
| 分红 | 东方财富RPT_SHAREBONUS_DET | 最近50条范围，原始方案/进度，不推造累计分红 |
| 公告/大宗 | 巨潮/东方财富适配器 | 限定记录数；旧适配器失败与空集合不能区分时标未获取或无披露，不能断言没有 |
| 宏观/指数成分 | 未接入已核验来源 | 宏观评分和新闻显示未获取；手工成分名单不进入产品 |
| IPO/商誉/关联/累计分红 | 当前运行链路未核验 | 列表未获取；不从代码、股价或市值推算 |

股票主表保留名称/代码/市场的既有收录目录；名单覆盖4601与股东披露覆盖5881是不同范围。新数据进入 `verified_source_cache` 与可信历史表。旧 `stock_quotes`/股东/分红等历史表保留供审计，产品读取时剥离不可信数字。

`available` 仅表示本接口所声明范围获取成功；`partial` 为部分覆盖，`stale` 为旧缓存，`unavailable` 为未获取。真实来源不代表未来结果有保证，技术指标是基于真实输入按公开工程规则计算的结果。
