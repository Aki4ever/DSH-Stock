### REQ-003: 经典技术指标与 100 分制量化多空评估模型
- **当前状态**：`[ACTIVE]` 生效中
- **实施版本**：`v1.0.0`
- **提出时间**：2026-09-16
- **核心诉求与目标**：
  1. 原生纯数学实现经典技术指标：简单移动平均线（MA5/MA10/MA20/MA60）、相对强弱指标（RSI-6/RSI-12/RSI-24）、平滑异同移动平均线（MACD: DIF/DEA/MACD柱）、布林带（BOLL: 上轨/中轨/下轨/带宽）、KDJ 随机指标；
  2. 自动识别多空信号：均线金叉/死叉、MACD金叉/死叉、RSI超买(>80)/超卖(<20)、布林破位等；
  3. 建立 100 分制量化评估模型：结合趋势面（35分）、动量面（25分）、均线支撑面（20分）、波动风险面（20分），输出综合评分与操作建议（强烈看多/偏多/震荡观望/偏空/高危规避）。
- **关联文件**：`scripts/stock_indicators.py`、`tests/test_stock_indicators.py`
- **验收标准**：
  - [x] 指标算法经标准数学公式验证，数值与标准金融终端一致；
  - [x] 100 分制评分逻辑覆盖完备，各区间评语及操作指引明确；
  - [x] 信号探测器可准确定位金叉/死叉与超买超卖状态。
