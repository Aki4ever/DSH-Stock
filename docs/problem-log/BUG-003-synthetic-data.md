# BUG-003 · 固定8姓名与产品合成数据

状态：已解决（v4.5.0本地技术验收，用户验收待确认）。关联REQ-009/010/011/012；UI-STOCK-LIST/UI-STOCK-DETAIL/UI-SHAREHOLDERS及仪表盘、宏观、指数。

表现：个人股东仅8个；来源失败时仍有行情/股东/财报/宏观数值；市值44/45字段反置；分时累计量额重复累加。

根因：旧 `shareholder_engine.py` 的固定8姓名列表，被确定性公式复用为股东；聚合截断为市值前800只。其他模块存在随机或固定样例回退、无来源旧缓存、缺失值转0以及前端估算成交额。源码证据保存在开工前备份与清单。

修复：采集东方财富真实分页，按标准化姓名跨股票/跨期去重；取消前800限制，聚合后分页。五类图形同源计算。所有产品合成路径禁用，可信缓存隔离旧数据，缺失/错误显式状态；分时直接接真实来源并将累计量额转差值。回退保留旧源码只供审计，不作为当前产品。

验证：1001个不同姓名测试（超过旧800截断）、跨期独有姓名、分页失败/重复、完整更新保留旧姓名、无来源缓存拒绝、Mock拒绝、财报缺失/季度差分、市值字段、分时缺成交额、5图层/开关/窗口坐标、真实1870页及实际页面19866个人姓名。见[本版验证](../verification/2026-09-20-r02/README.md)。

恢复复盘：9月19日中断时存在报告f-string语法错误；9月20日从首个未验收阶段恢复，先compileall修复语法，再回归与页面验证；没有重复重建任务或删除旧库。工作流标题必须保留开场分32，当前难度68单独记录；本地检查点按R编号显示“调研”的旧派生标签不改变用户已授权的软件实施范围。
