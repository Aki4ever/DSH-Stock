# 自动化测试与质量门禁 (tests) 说明文档

## 📌 目录定位
- **路径**：`tests/`
- **主要作用**：用于存放本工程的全量自动化单元测试与集成测试套件，执行“需求即断言、100% 绿灯门禁”质量法典。

---

## 📋 文件收纳与命名规范
1. **文件分类**：采用 Python 标准 `unittest` 框架的测试模块；
2. **命名格式**：统一以 `test_*.py` 命名；
3. **关联文档**：每个测试用例均映射具体的需求点（如 `REQ-xxx`）。

---

## 🛠️ 维护与更新原则
- 测试必须能在无外网、零外部三方依赖的环境下通过内置 Mock 数据稳定通过；
- 交付前必须在终端实际运行并通过全量测试，严禁带病交付。
