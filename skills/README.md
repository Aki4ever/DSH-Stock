# Agent 技能包与扩展规范 (skills) 说明文档

## 📌 目录定位
- **路径**：`skills/`
- **主要作用**：用于存放 DSH Agent 动态加载的技能声明包（`SKILL.md` / `stock_skill.json`），实现大模型会话内无缝调用股票行情、指标分析与持仓研判能力。

---

## 📋 文件收纳与命名规范
1. **文件分类**：标准 DSH Agent Skill 声明文档与能力描述清单；
2. **命名格式**：采用 `SKILL.md` 与小写 JSON 配置；
3. **关联文档**：与 DSH 宿主基座能力全景严格映射。

---

## 🛠️ 维护与更新原则
- 技能接口必须包含正向使用场景（When to use）与反例约束（When NOT to use），防止调用幻觉；
- 参数 Schema 规范必须完备清晰。
