# DSH 股票量化与自选监控技能清单 (SKILL.md)

> ### 🏷️ **技能元数据**
> - **技能代号**：`dsh_stock_analysis`
> - **版本**：`v1.0.0`
> - **适用宿主**：DeepSeek Harness (DSH) Agent 基座
> - **运行基准**：Python 3.9+（零外部三方依赖）

---

## 🎯 技能定位与核心职责
本技能为 DSH 智能体提供针对中国 A 股、大盘指数及重点自选标的的实时行情抓取、技术指标计算、100 分制多空量化评分、持仓投资组合监控、止盈止损风险预警以及原生矢量 SVG 走势图表与 Markdown 综合研报的自动生成能力。

---

## 🛠️ 子能力调用矩阵与边界约束

### 1. 实时行情秒查 (`get_stock_quote`)
- **正向触发**：用户问及“茅台今天多少钱”、“上证指数今天涨跌”、“查一下 600519 和 300750 行情”；
- **反例约束**：非证券代码或用户查询无涉股价的百科信息时坚决不调；
- **调用方式**：
  ```bash
  python3 scripts/dsh_stock_cli.py quote 600519 300750 sh000001
  ```

### 2. 100分制多空量化体检 (`analyze_stock_quant`)
- **正向触发**：用户要求“深度分析某股票”、“宁德时代现在能进场吗”、“分析下比亚迪的技术面”；
- **反例约束**：用户仅要价格数字时免调全量指标计算；
- **调用方式**：
  ```bash
  python3 scripts/dsh_stock_cli.py analyze 300750
  ```

### 3. 投资组合持仓诊断与预警 (`check_portfolio_status`)
- **正向触发**：用户询问“我现在的持仓盈亏如何”、“有没有触碰止损的股票”、“组合风险怎么样”；
- **反例约束**：用户询问未建仓股票时不要调用组合诊断；
- **调用方式**：
  ```bash
  python3 scripts/dsh_stock_cli.py portfolio
  ```

### 4. 矢量 SVG 走势图绘制 (`generate_stock_chart`)
- **正向触发**：用户需要看走势图、K线图或要求输出图表直达文件；
- **反例约束**：纯文本问答无需反复生成 SVG 文件；
- **调用方式**：
  ```bash
  python3 scripts/dsh_stock_cli.py chart 600519
  ```

### 5. 每日全盘研报一键出刊 (`generate_stock_daily_report`)
- **正向触发**：收盘总结、每日行情全盘扫描或生成完整分析研报文档；
- **反例约束**：单点查询时避免全量触发生成全盘大文件；
- **调用方式**架构：
  ```bash
  python3 scripts/dsh_stock_cli.py report
  ```
