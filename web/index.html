📖 体检规则与口径说明（点击展开）

前置门禁：持仓底册必须已核实（config/stock_config.json 的 portfolio_verified=true）。 未核实时本页不产出任何盈亏或风险结论，也不做任何统计——避免把样例或占位持仓当成真实持仓。

静态规则

  • S1 止盈达标：累计收益率 ≥ +20%（阈值可在 alert_rules 调整）。
  • S2 止损击穿：累计收益率 ≤ -8%。
  • S3 日内异动：当日涨跌幅 ≥ +5% 或 ≤ -5%。

动态规则

  • D1 MA20 破位：最新收盘价跌破 MA20（周期可配置）。
  • D2 日线卖点：复用 REQ-019 引擎的日线 S1/S2/S3，随信号携带规则版本与可执行性。
  • D3 移动止盈回撤：自持仓期内最高价回撤 ≥ 8%。峰值取自买入日之后的日线最高价； 若买入日早于来源覆盖起点，会明确标注峰值可能被低估，不假装覆盖完整。

不可判定：日线未获取或K线不足时，相关规则标注为「无法判定」而不是「未触发」—— 没有数据与没有风险是两件完全不同的事。

行情口径：真实多源行情，任一必需字段缺失即报错，绝不补 0 或猜测。

📖 判定规则与口径说明（点击展开）

买点（与卖点严格对称）

  • 1B 第一类买点：向下笔价格创出新低，但 MACD 绝对柱面积较前一同向笔减弱（笔级底背离）。
  • 2B 第二类买点：下跌笔 → 反弹笔 → 回调笔，回调低点高于前一下跌笔低点。
  • 3B 第三类买点：向上笔突破笔中枢上沿 ZG，随后回抽笔低点不低于 ZG。

卖点

  • S1 第一类卖点：向上笔价格创出新高，但 MACD 绝对柱面积减弱（笔级顶背离）。
  • S2 第二类卖点：上涨笔 → 回调笔 → 反抽笔，反抽高点低于前一上涨笔高点。
  • S3 第三类卖点：向下笔跌破笔中枢下沿 ZD，随后反抽笔高点不高于 ZD。

区间套：30 分钟信号必须落在同向日线结构区间内才判定为共振；否则标注「单周期·已降级」并写明原因。

可执行性：买点结构止损高于现价（或卖点结构止损低于现价）说明结构已被证伪；结构止损距离超过 15% 或结构尚未确认时，均不给建议股数。建议股数按单笔最大亏损 2%、单只不超过总资金 30%、100 股整手计算，仅为资金管理参数。

数据来源：日线为可信不复权历史（与产品同一口径），30 分钟为真实公开分钟线；来源未获取则该周期不产出任何信号。

! 水平辅助线指标口径说明（交汇成交额 / 交易面积）

以下口径与图表内标签、图层管理面板数值同源同一算法，不另设口径

📏 一、交汇成交额（既有指标）
某条辅助线价格记作 P。对每根 K 线，若满足 low ≤ P ≤ high，则该 K 线与该辅助线「交汇」。
交汇成交额＝所有交汇 K 线的成交额之和；交汇交易日＝交汇 K 线的根数（分时周期下即为交汇的分钟点数）。
📐 二、交易面积（本指标）
定义：从该辅助线首个与 K 线交汇的交易日起，至今天（最后一根可用 K 线）为止，剔除该线自身交汇的那些交易日后，剩余交易日对应的 K 线成交额之和。
等价说法：这段区间里「没有落在辅助线上的 K 线」的成交额总和。 
D         = 该线全部交汇交易日集合 { d | low_d ≤ P ≤ high_d }
d_first   = min(D)                        // 无交汇 → 交易面积无定义，显示「未交汇」
T         = { d | d_first ≤ d ≤ 今天 }
S_area(P) = Σ amount(d)   for d in (T \ D)
三条口径铁律：
① 累计口径：区间为「首个交汇日 → 今天」，不受当前缩放窗口影响（缩放到 5 根时该数值不变）；
② 必须剔除该线自身交汇的交易日，只统计没有落在辅助线上的 K 线；
③ 区间内若存在成交额不可得的交易日，标签显式标注「覆盖不完整」，绝不以 0 补齐、绝不静默出数。
💰 三、成交额取值与兜底口径（REQ-025）
取值优先级（逐级降级，前一级取到即停止）：
  1) 来源直接提供的成交额；
  2) 来源提供的原始成交额（元）÷ 1e8 折算为亿元；
  3) 兜底：成交额(亿元) = 当日均价 × 当日成交量 ÷ 1e8，其中日 K 均价 = (开 + 收 + 高 + 低) / 4；分时均价优先取该分钟均价，缺失时退化为该分钟成交价。
凡使用第 3 级兜底的数据与指标，统一以「（估算：均价×成交量）」后缀标注，与来源原始披露值严格区分。
若连均价与成交量都缺失，则该周期不生成自动多阶线，并显式说明原因，不以 0 参与排序或求和。
🤖 四、自动多阶线的排序与约束
在候选价位池中按交汇成交额降序求解 1~4 根线：第 x 根线的交汇成交额排第 x 大，且其交汇交易日集合不得与已选线完全重复（S_x ≠ S_i），同时相邻线价格保持适度区分。
无任何价位满足约束时，本周期不生成自动线并显式说明，而不是画一根凑数线。
ℹ️ 五、数据不足时的展示规则
系统遵循「禁止虚构数据」底座：不可测算时显示「无法测算」并附具体原因（如成交额与成交量均缺失、无分时明细、无满足约束的价位），不会显示 0 根、0 元或任何推测数值。
