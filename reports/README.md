# 报告与图表归档 (reports) 说明文档

## 📌 目录定位
- **路径**：`reports/`
- **主要作用**：用于存放每日股票行情分析报告（Markdown 格式）以及自动渲染的矢量 SVG 行情图表、K线图与技术指标看板。

---

## 📋 文件收纳与命名规范
1. **文件分类**：Markdown 报告与 SVG 矢量图表，不存放临时缓存；
2. **命名格式**：
   - 综合报告：`reports/stock_report_YYYY-MM-DD.md`
   - 股票图表：`reports/charts/chart_[code]_[YYYYMMDD].svg`
3. **关联文档**：所有产出物需在会话尾部提供可直接点击的相对路径。

---

## 🛠️ 维护与更新原则
- 图表均生成为标准的独立 SVG 格式，可直接在浏览器或 DSH 中无缝预览；
- 遵循磁盘自愈清理机制，支持历史报表归档与滚动保留。
